# Release Notes: v0.4.1.2

**Date**: 2026-10-30  
**Type**: Patch release (no migrations, no new settings, no breaking changes)  
**Scope**: Vietnamese admin: login password label, KPI comparisons, dated 28-day chart, Markdown editor; failed sign-in no longer echoes the password

---

## Summary

v0.4.1.2 fixes admin text that read badly in Vietnamese, found while reviewing Sense Sphere's admin
(White-Neuron/WN-Sense#194). The login page's password label, the home page KPI cards, the 28-day
chart and the Markdown editor now read properly in every language. A failed sign-in also no longer
writes the typed password back into the page's HTML.

---

## Fixed

### Login form (PR #29)
- `LoginForm` redefined the `password` field without a label, so it read "Password" in every
  language. It now has `label=_("Password")` and `strip=False`, like `AuthenticationForm`'s own
  field.
- **Security**: the widget had `render_value=True`, so a failed sign-in wrote the password typed
  into the page's `value="..."` (visible in the page source, page caches and to extensions). It is
  removed, and the field has `autocomplete="current-password"`.

### Home page KPI cards (PR #29)
- The footer compares with a whole translatable phrase per period instead of
  "progress from last - week":

  | Period | English | Vietnamese |
  |---|---|---|
  | today | vs. yesterday | so với hôm qua |
  | 7days | vs. the 7 days before | so với 7 ngày trước đó |
  | week | vs. last week | so với tuần trước |
  | month | vs. last month | so với tháng trước |
  | year | vs. last year | so với năm trước |

- Card titles keep clear of the label in the card's corner. With the shorter footer the cards got
  narrower, and "Lượt truy cập trong tuần" ran under "KHÁCH ẨN DANH". Unfold's CSS has no `pr-32`,
  so the room is an inline style.

### Markdown editor (PR #29)
The header button, placeholder, aria labels and preview dialog title are translated. `mdeditor.js`
reads the button and dialog labels from `data-md-preview-label` / `data-md-preview-title` on the
widget, with the English text as fallback.

---

## Changed
- The 28-day activity chart is labelled with dates (`03/10` … `30/10`) instead of weekday names
  repeated four times.
- The dashboard stats cache key is now `wn:dashboard:v2:<period>:<date>`. Entries cached by 0.4.1.1
  have no dates, so they are not reused.

## Compatibility / Upgrade

```bash
pip install -U django-whiteneuron==0.4.1.2
python manage.py collectstatic
```

- No migrations, no new settings.
- `collectstatic` is needed for `base/forms/js/mdeditor.js`.
- Projects that override `admin/header.html` or `base/forms/mdeditor.html` keep their own template.
  To get the translated editor labels, add the `data-md-preview-label` / `data-md-preview-title`
  attributes to the `.mdeditor-container`.
- Projects that subclass `LoginForm` and relied on the password being re-rendered after a failed
  sign-in must now set `render_value=True` themselves (not recommended).
- Translators: new msgids "Password", "vs. yesterday", "vs. the 7 days before", "vs. last week",
  "vs. last month", "vs. last year", "Markdown preview", "Preview markdown",
  "Write your markdown here...", "Markdown editor" (Vietnamese included). "progress from last" and
  the weekday names are no longer used by the dashboard.
- Docker base images `django-whiteneuron-{alpine,debian}:v0.4.1.2` are published by the release
  workflow; WN-Sense can set `BASE=v0.4.1.2`.

### Rollback
Revert to v0.4.1.1. There are no schema or settings changes. The `v2` cache entries expire on their
own.
