# Release Notes: v0.3.7.0

**Date**: 2026-08-23  
**Type**: Security Patch  
**Scope**: 6 CVEs across django, cryptography, sqlparse, setuptools

---

## Summary

This release addresses 6 security vulnerabilities across core dependencies. Django is upgraded to patch a GeoDjango DoS vulnerability (CVE-2026-15830), pyopenssl is bumped to resolve the Bleichenbacher oracle attack via cryptography (CVE-2026-69247), sqlparse transitive dependencies are fixed for 3 DoS CVEs, and setuptools build-system dependency is patched. No code changes — this is a pure dependency security update.

---

## Changes

### Fixed

- **`pyproject.toml`** — Django lower bound bumped from `>=6.0.8` to patch CVE-2026-15830 (GeoDjango DoS).
- **`pyproject.toml`** — pyopenssl minimum version bumped from `>=26.2.0` to `>=26.4.0` — resolves CVE-2026-69247 (Bleichenbacher oracle attack, patched in cryptography 50.0.0).
- **`pyproject.toml`** — Added `sqlparse >=0.6.0` via transitive dependency resolution — patches CVE-2026-71491, CVE-2026-54284, CVE-2026-59893 (DoS vulnerabilities).
- **`pyproject.toml`** — Added `setuptools >=75.1.0` to `[build-system]` requires — patches CVE-2025-47273.
- **`pyproject.toml`** — Removed direct `cryptography` dependency (not used directly in code, only needed as transitive dep via pyopenssl).
