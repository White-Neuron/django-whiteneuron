# Release Notes: v0.3.6.0

**Date**: 2026-08-13  
**Type**: Bugfix  
**Scope**: UUID regeneration in duplicate_objects action

---

## Summary

This release fixes a bug in `ModelAdmin.duplicate_objects()` where duplicated objects with a UUID field would fail with an `IntegrityError` due to unique constraint violation. The fix regenerates the UUID via `uuid4()` before clearing `pk`, ensuring each duplicated object gets a fresh, unique identifier.

---

## Changes

### Fixed

- **`whiteneuron/base/modeladmin.py`** — `duplicate_objects()` now regenerates the `uuid` field on copied objects using `uuid4()` before setting `pk=None`. This prevents `IntegrityError` when the User model's unique `uuid` constraint is violated during object duplication. The fix dynamically detects UUID fields across all models, not just the User model.
