# Release v0.3.4.13 — 2026-07-04

## Summary

Migrate `md2html-tailwind4` dependency from git-based resolution to PyPI registry, simplifying dependency management and enabling standard package index resolution with verified hashes.

## Main Changes

### Updated
- **md2html-tailwind4**: Changed from git source (`https://github.com/White-Neuron/md2html-tailwind4?rev=v1.5.1`) to PyPI registry (`>=1.5.2`). The package is now resolved via standard Python Package Index with SHA256-verified wheels and sdist.

## Files Changed

| File | Change |
|------|--------|
| `pyproject.toml` | Updated `md2html-tailwind4` specifier from `==1.5.1` to `>=1.5.2` |

| `CHANGELOG.md` | Added v0.3.4.13 entry |

## Compatibility Notes

- No breaking changes; safe for all v0.3.x users.

- All existing functionality preserved.
