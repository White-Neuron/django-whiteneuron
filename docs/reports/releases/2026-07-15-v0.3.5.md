# Release v0.3.5 — 2026-07-15

## Summary

This release introduces public/private access control for all file types (Excel, PDF) and adds support for a new HTML file type with inline browser preview. File administrators can now restrict file downloads to specific users or groups via the admin interface.

## Main Changes

### Added
- `is_public`, `allowed_users`, `allowed_groups` fields on `BaseFile` model — files default to public (`is_public=True`) for backward compatibility.
- `_check_access()` permission logic in download and preview views — enforces access control before serving files; redirects unauthenticated users to login, returns 403 for unauthorized access.
- `preview_file` view for inline HTML file preview in browser after permission check.
- `HTMLFile` model with migration — new file type alongside Excel and PDF.
- Admin public/private badge column (`is_public_badge`) on all file changelists.
- Conditional Access Control fieldset in admin change form — shown only when a file is marked private.

### Fixed
- No breaking changes; all existing files remain publicly accessible by default.

## Compatibility Notes

- **No breaking changes** — all existing files default to public (`is_public=True`).
- New migrations add columns and tables; no data loss expected.
- Requires `python manage.py migrate` after upgrade.
- Compatible with Django 6.0.x and Python 3.13+.

## Upgrade Guide

```bash
pip install --upgrade django-whiteneuron==0.3.5
python manage.py migrate
```

### Rollback

Safe to revert to v0.3.4.14:
```bash
pip install django-whiteneuron==0.3.4.14
python manage.py migrate  # rollback migrations if needed
```
