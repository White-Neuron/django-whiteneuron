# Release Notes: v0.4.1.1

**Date**: 2026-10-21  
**Type**: Patch release (no migrations, no new settings, no breaking changes)  
**Scope**: CKEditor theme in light and dark mode; "Log in as guest" button and guest login errors

---

## Summary

v0.4.1.1 fixes two things that looked broken to admin users. CKEditor fields were transparent, and
in dark mode their text was black on a dark background. The guest login button had no background,
and when no guest account was usable it did nothing. Both now work in light mode, dark mode and
every daisyUI theme.

---

## Fixed

### CKEditor theme (PR #27)
`CKEDITOR_5_CUSTOM_CSS = "base/css/ckeditor5.css"` is linked as-is by django-ckeditor-5, but the
file was Tailwind source that no build step compiled. Browsers dropped 100 of its 108 rules, and the
`theme()` values made the `--ck-color-*` overrides invalid. The editor and toolbar became
transparent, and in dark mode the content kept CKEditor's black text.

The file is now plain CSS with no build step. It only overrides CKEditor's `--ck-*` variables, which
is CKEditor's documented theming method, so every editor feature keeps CKEditor's own styles.

| Mode | What follows Unfold's colors |
|---|---|
| Light | borders, text, focus border and glow, links, "on" buttons; content font Inter |
| Dark (`html.dark`) | the base colors most of CKEditor's UI derives from, plus every fixed light color that would be unreadable: buttons and inputs, placeholders, selection, links, shadows, captions and their highlight flash, the keyboard shortcuts dialog (Alt+0), the style panel, table border helpers, content text |
| Dark, rules | code block text, todo checkbox borders, find & replace matches (colors CKEditor sets without a variable) |

Dark mode follows Unfold's `dark` class on `<html>`, which dark daisyUI themes also set.

### "Log in as guest" (PR #26)
- The button used `bg-secondary-600`, which was never compiled into `styles.css`, so it read as plain
  text. It now uses Unfold's secondary button, like the other login buttons.
- The button appears only when an active staff `guest` account exists. The check is the new
  `{% guest_login_available %}` tag (`{% load wn_guest %}`), so it works on any admin site that
  renders `admin/login.html`.
- `GuestLoginView`:
  - shows "Guest login is not available." when the login fails, and returns to the login page with
    the original `?next`
  - is marked `login_not_required`, so it works with Django's `LoginRequiredMiddleware`
  - lets any logged-in user on the login page switch to guest
  - restores the previous session when the switch fails, instead of returning a 500 (read-only
    database with DB-backed sessions). A read-only database that refuses only the `last_login`
    write (demo mode) still logs the guest in, as before
  - accepts `?next` only on the same host and scheme
- `AutoGuestLoginMiddleware` resolved `?next` as a URL name, so `?next=/admin/foo/` raised
  `NoReverseMatch`. It now redirects to the URL, and logs failures instead of ignoring them.

## Changed
- Tailwind no longer scans its own output (`whiteneuron/static/base/css/styles.css`). Removed
  utilities kept their theme variables alive, so rebuilds weren't reproducible.
- `docs/CKEDITOR5_CUSTOMIZATION.md` is rewritten. It described a build step and a JS file that
  don't exist.

## Tests
- `GuestLoginButtonTests`, `AutoGuestLoginMiddlewareTests` (13 tests).
- `CKEditorCustomCssTests`:
  - the packaged `ckeditor5.css` contains no Tailwind syntax (`@apply`, `theme(`, `@theme`,
    `@utility`, `@variant`, ...)
  - every fixed light color in CKEditor's CSS is overridden for dark mode or listed as reviewed
    (accents, translucent overlays, badges). A django-ckeditor-5 upgrade that adds one fails the
    suite instead of shipping light-on-dark text.

## Compatibility / Upgrade

```bash
pip install -U django-whiteneuron==0.4.1.1
python manage.py collectstatic
```

- No migrations, no new settings.
- Projects that set their own `CKEDITOR_5_CUSTOM_CSS` are unaffected. To build on the packaged theme
  instead of replacing it, start your file with
  `@import url("../../base/css/ckeditor5.css");` (path relative to your file) and override
  variables after it. See `docs/CKEDITOR5_CUSTOMIZATION.md`.
- Projects that override `admin/login_after.html` keep their own button. To hide it when no guest
  account exists, wrap it in `{% load wn_guest %}{% guest_login_available as can_guest %}{% if can_guest %}...{% endif %}`.
- Translators: new msgid `Guest login is not available.` (Vietnamese included).
- Docker base images `django-whiteneuron-{alpine,debian}:v0.4.1.1` are published by the release
  workflow; WN-Sense can set `BASE=v0.4.1.1`.

### Known issues (unchanged)
- Unfold's preflight resets typography inside the editor (headings at body size, hidden list
  bullets).
- `AutoGuestLoginMiddleware` is enabled when `SKIP_GUEST_LOGIN=True`, the opposite of what the name
  suggests. It is kept as is because changing it would affect existing projects.

### Rollback
Revert to v0.4.1.0. There are no schema or settings changes.
