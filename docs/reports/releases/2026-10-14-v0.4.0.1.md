# Release Notes: v0.4.0.1

**Date**: 2026-10-14  
**Type**: Patch release (bug fixes, no migrations)  
**Scope**: Vietnamese translations, daisyUI modals under Unfold, announcement endpoint

---

## Summary

v0.4.0.1 fixes three issues reported against v0.4.0.0. Vietnamese translations that the release
dropped are restored, daisyUI modals render correctly again under Unfold's dialog styles, and the
announcement endpoint no longer returns a 500 when its project template is missing. New tests stop
the translation problem from coming back.

---

## Fixed

### Translations dropped in 0.4.0.0
`makemessages` (xgettext) can't read `_()` calls *inside f-strings*. When the catalog was regenerated
for 0.4.0.0, the strings used only that way were marked obsolete (`#~`) and left out of `django.mo`,
so they showed in English:

| String | Where |
|---|---|
| Inactive, Admin, Bot | user grid badges and role icons |
| has been updated by user | title of every update notification |
| added, removed | M2M change notes in notifications |
| progress from last, in | dashboard KPI cards |

- The `_()` calls are moved out of the f-strings (`base/admin.py`, `base/models.py`,
  `dashboard/views.py`) and the translations are restored. "Admin" (role badge) is now
  "Quản trị", and "Bot" stays "Bot".
- Dashboard KPI cards use whole sentences with named placeholders: `%(object)s in %(period)s`
  ("Hoạt động trong tuần") and `%(count)s successful (%(rate)s%%)`. The hard-coded English "day" and
  "successful" are translated. No change now shows as a green +0 instead of a red -0, and the
  color classes are literal so Tailwind compiles them.
- Notification bodies ("… has been updated by user … with the following changes") were hard-coded
  English (already in 0.3.x). They are now translated.

### daisyUI modals
Unfold styles every `<dialog>` with an unlayered rule: a centered 28rem white card with padding,
`translate(-50%, -50%)` and `position: relative`. Unlayered CSS beats daisyUI's layered `.ui-modal`
whatever the specificity, so an open `ui-modal` rendered as a narrow white column with no overlay.
This affected the announcement dialog, the feedback "resolve" dialogs and the markdown preview.
A `dialog.ui-modal` rule in `styles.css` restores the full-screen modal with its dimmed overlay.
It is the only unlayered Unfold rule on a bare element; the other daisyUI components the package
uses aren't affected.

### Announcement endpoint
`/announcement/` rendered `ANNOUNCEMENT_CONTENT_HTML_FILE` and returned a 500 if the
project-provided template didn't exist, or returned `None` if the setting was empty. Both cases
now return empty content, and a missing template is logged as a warning.

## Tests
- No gettext call inside an f-string anywhere in the package.
- Every literal msgid in the package's Python code is present in the compiled Vietnamese catalog
  (or translated by Django/Unfold). This catches strings that `makemessages` drops.
- The dashboard KPI card is fully translated in Vietnamese.
- `styles.css` carries the `dialog.ui-modal` override.
- The announcement endpoint works without a template and with an empty setting.

All of these fail on v0.4.0.0 and pass on v0.4.0.1.

---

## Compatibility / Upgrade

```bash
pip install -U django-whiteneuron==0.4.0.1
python manage.py collectstatic
```

- No migrations and no settings changes.
- Translators: new msgids `with the following changes`, `%(object)s in %(period)s` and
  `%(count)s successful (%(rate)s%%)`; `in` is no longer used.
- Docker base images `django-whiteneuron-{alpine,debian}:v0.4.0.1` are published by the release
  workflow; WN-Sense can set `BASE=v0.4.0.1`.
