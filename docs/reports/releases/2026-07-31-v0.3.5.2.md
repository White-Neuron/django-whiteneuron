# Release v0.3.5.2 — Email System Improvements & User Creation Hardening

**Release Date**: 2026-07-31  
**Previous Version**: v0.3.5.1  

## Summary

This release focuses on three key areas: email sender customization via `EMAIL_ALIAS_USER`, a complete redesign of the email signature template (reducing ~230 lines of inline CSS), and hardening the user creation flow with better validation and error handling.

## Main Changes

### Added
- **`EMAIL_ALIAS_USER` setting** — New `.env` variable and Django settings entry that allows configuring an alias name for the email sender displayed to end users in login notification emails.
- **PNG logo asset** — New `static/base/images/logo/LOGO.jpg` (17KB) for use in email signatures with rounded corners styling.

### Fixed
- **User creation password race condition** — In `UserCreationForm.save_model()`, password is now set *after* `super().save_model()` completes, preventing the password from being overwritten during form processing.
- **Duplicate email validation** — Added explicit duplicate email check in `UserCreationForm` to prevent creating users with existing email addresses before the model-level unique constraint fires.
- **Graceful email error handling** — Email sending in user creation is now wrapped in try/except, so a failed SMTP connection does not block user creation entirely.

### Improved
- **Email signature template overhaul** — `templates/admin/signature.html` rewritten from ~250 lines of inline CSS to a clean, DaisyUI-based structure. Net reduction: 231 lines removed, 16 added. The new template is easier to maintain and more compatible with email clients.

## Compatibility Notes

- **No breaking changes** — All changes are backward compatible.
- **Python**: Requires Python 3.13+ (unchanged from v0.3.5.1).
- **Django**: Compatible with Django 6.0.x (unchanged).
- **Schema**: No database migrations required.
- **Dependencies**: No dependency changes.

## Upgrade Guidance

```bash
pip install --upgrade django-whiteneuron
# or
uv add "django-whiteneuron==0.3.5.2"
```

No manual migration needed — this release contains no schema changes.

To configure the new `EMAIL_ALIAS_USER` setting, add to your `.env`:

```env
EMAIL_ALIAS_USER=White Neuron Admin
```

## Rollback

Safe to rollback to v0.3.5.1:

```bash
pip install django-whiteneuron==0.3.5.1
```

No data loss or schema changes to revert.
