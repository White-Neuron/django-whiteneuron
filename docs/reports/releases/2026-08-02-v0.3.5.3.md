# Release Notes: v0.3.5.3

**Date**: 2026-08-02  
**Type**: Security Patch  
**Scope**: Django dependency upgrade to patch 3 CVEs

---

## Summary

This release upgrades the `django` package lower bound from `>=6.0.6` to `>=6.0.7,<7.0.0`, addressing three medium-severity security vulnerabilities in Django 6.0.x. No application code changes, migrations, or schema modifications are required.

---

## Security Fixes

| CVE | Severity (CVSS) | Description |
|-----|-----------------|-------------|
| CVE-2026-53877 | 6.3 Medium | Django security vulnerability patched in 6.0.6+ |
| CVE-2026-48588 | 5.3 Medium | Django security vulnerability patched in 6.0.6+ |
| CVE-2026-53878 | 5.3 Medium | Django security vulnerability patched in 6.0.6+ |

All three CVEs are resolved by upgrading to Django 6.0.7 or later.

| File | Change |

## Compatibility Notes

- **Django version**: 6.0.x only (upper bound `<7.0.0` enforced)
- **Python version**: >=3.13 (unchanged)
- **Breaking changes**: None
- **Schema changes**: None — no migrations required

## Upgrade Guidance

### From PyPI
```bash
pip install --upgrade django-whiteneuron
```

### From local source
```bash
uv pip install -e .
```

No manual migration or configuration changes are required. The upgrade is transparent and safe for all v0.3.x deployments.

## Rollback

No data loss or schema rollback required — this release contains no database changes.
