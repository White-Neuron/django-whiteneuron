# Release Notes: v0.3.8.0

**Date**: 2026-09-25  
**Type**: Bugfix  
**Scope**: Django 6 compatibility, admin UI fixes, sidebar feature flag

---

## Summary

This release bundles three bugfixes shipped since v0.3.7.0: a Django 6 `format_html()` crash in the Image model's admin thumbnail/preview methods, broken mosaic thumbnail URLs on the app changelist when thumbnails use relative static paths, and the `SHOW_FILE_MANAGEMENT` feature flag that was silently ignored because sidebar post-processing matched gettext-lazy titles as plain strings. No new features, no dependency changes, no schema changes.

---

## Changes

### Fixed

- **`whiteneuron/base/models.py`** — `Image.imgThumbnail()` and `Image.imgPreview()`: replaced f-string interpolation inside `format_html()` with the proper template + args pattern (e.g. `format_html('<p>{}</p>', mes)`). Resolves the rendering crash on Django 6 and ensures interpolated values are HTML-escaped.
- **`whiteneuron/templates/admin/base/app_change_list.html`** — Mosaic thumbnails: relative `thumbnail_url` paths are now wrapped in `{% static %}`; URLs starting with `//` or `http` pass through unchanged. Applied to both the 4-app and full-list branches, consistent with existing `icon` handling.
- **`whiteneuron/base/settings.py`** — `SHOW_FILE_MANAGEMENT`: the Unfold sidebar is now built conditionally at definition time (`FILE_MANAGEMENT_ITEMS` extracted to a module-level constant; the File Management section is included only when the flag is enabled). The previous post-processing loop compared lazy gettext titles with `isinstance(title, str)`, which was always False, so the section was never removed. When disabled, its items merge into the System section before Notifications config — same intent as before, now reliable.

### Improved

- **`whiteneuron/base/settings.py`** — Feature flags are defined in a dedicated block before `UNFOLD`, making conditional sidebar construction explicit and removing fragile string-based navigation surgery.
- **`.gitignore`** — Added `AGENTS.md` to ignored files.
