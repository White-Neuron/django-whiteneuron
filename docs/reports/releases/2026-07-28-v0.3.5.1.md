# Release v0.3.5.1 (2026-07-28)

## Scope Summary

Patch release addressing email preview rendering issues in Django admin and cleaning up code quality problems (duplicate import, debug print statement). No schema changes or breaking changes introduced.

## Main Changes

### Fixed
- **`whiteneuron/base/admin.py`** — `MailAdmin.preview_email()` now renders email content inside a sandboxed `<iframe>` using base64-encoded data URI instead of inline HTML rendering via `mark_safe()`. This prevents CSS conflicts between email content styles and the Django admin theme (Unfold/daisyUI).
- **`whiteneuron/base/admin.py`** — Removed duplicate `static` import from `django.templatetags.static` (was imported on lines 15 and 65).
- **`whiteneuron/base/admin.py`** — Removed debug `print(fieldsets)` statement from `UserProfileAdmin.get_fieldsets()` that was outputting to stdout during admin requests.
